# Hermes Field Guide

A concise, practical documentation site for Hermes Agent: setup, providers, surfaces, tools, MCP servers, skills, memory, automation, multi-agent operations, and safety.

## Stack

- Next.js 16 static export
- React 19
- Tailwind CSS 3
- TypeScript
- GitHub Pages via GitHub Actions

## Development

```bash
npm install
npm run dev
npm run build
npm run lint
```

The site is generated as a static export in `out/`.

## Sources

Content is a summarized orientation based on the official Hermes documentation and source repository:

- https://hermes-agent.nousresearch.com/docs/
- https://hermes-agent.nousresearch.com/docs/llms.txt
- https://github.com/NousResearch/hermes-agent

This guide intentionally keeps credentials, tokens, and private configuration out of the repository.
